# Start Here: Your Web Developer to AppSec Path

Use this first.

## Recommended Files

1. `full_stack_appsec_curriculum.md`
   - Your main path.
   - Starts from absolute beginner basics, then builds toward your background: frontend-heavy full-stack developer on Mac M2 Pro.
   - Focuses on web, API, Node/Express/Postgres, auth, Burp, OWASP, secure deployment, and portfolio projects.

2. `../cyber_guardians_curriculum.md`
   - Keep as the broad reference.
   - Use later for blue team, forensics, malware, general networking, and wider cybersecurity branches.

3. `../cyber_guardians_app.html`
   - Interactive version of the broad course.
   - Useful, but not the priority path for you right now.

## Your Priority Order

1. Set up the Mac M2 Pro lab from `full_stack_appsec_curriculum.md`.
2. Do Phase 0 even if it feels familiar: computer, web, backend, database, terminal.
3. Learn HTTP, DNS, TLS, cookies, CORS, and CLI basics.
4. Go deep on browser security: XSS, CSRF, CSP, storage, same-origin policy.
5. Strengthen backend security: Express, validation, SQL injection, Postgres, API authorization.
6. Learn Burp Suite with PortSwigger Web Security Academy.
7. Study auth deeply: sessions, JWT, OAuth/OIDC, password reset, MFA.
8. Add DevSecOps: gitleaks, semgrep, trivy, npm audit, GitHub Actions.
9. Build portfolio capstones.
10. Return to the broad Cyber Guardians course later.

## First 7 Days

Day 1:

- Read `Who This Course Is For`.
- Read `Absolute Beginner Orientation`.
- Read `Priority Learning Map`.
- Read `Ethics, Scope, and Legal Safety`.

Day 2:

- Install Homebrew and Xcode Command Line Tools.
- Install core developer tools.

Day 3:

- Install Docker Desktop.
- Run OWASP Juice Shop locally.

Day 4:

- Install Firefox Developer Edition, FoxyProxy, Burp Suite, and OWASP ZAP.
- Configure Burp with Firefox.

Day 5:

- Start Phase 0.
- Revisit computer, internet, website, backend, and database basics from a security mindset.

Day 6:

- Practice terminal basics.
- Write notes in your AppSec journal.

Day 7:

- Finish the Phase 0 journal deliverable.
- Then move into HTTP requests/responses.

## Main Rule

Do not try to become a general cybersecurity expert first. Become a secure web application developer first. That is the shortest, strongest bridge from where you are now.
